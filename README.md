# KLTN - Fraud ABM

Research workspace cho khóa luận về **Agent-Based Modelling (ABM) trong thử nghiệm/stress-testing chính sách quản lý gian lận giao dịch**.

## Legacy project

Khóa luận phát triển từ repo `FinRisk-ABM-Policy-Simulation`, nơi đã có synthetic transaction simulation, risk-model experiments, policy comparison, analyst-capacity scenarios, cost sensitivity và prototype dashboard.

KLTN mới không copy nguyên kết luận cũ. Mục tiêu là nâng cấp theo hướng empirical grounding, dynamic state/queue, uncertainty, validation và claim discipline.

## Git workflow

- `main`: bản đã chấp nhận.
- `chatgpt-draft`: thay đổi do ChatGPT chuẩn bị để review trước khi merge.

Không lưu API key, mật khẩu, token hoặc dữ liệu nội bộ nhạy cảm vào repository.
